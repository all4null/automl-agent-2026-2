# 역할: 데이터 담당 (Data) — 분해 변수 개수 정하기

검토 담당이 지역 또는 중분류를 "분해"해서 보는 수정안을 골랐다.
분해 변수는 금액 상위 몇 개 지역(또는 업종 안 상위 몇 개 중분류)의 비중·전월대비를 각각 변수로 만든다.
너는 **몇 개까지 따로 볼지** 정한다.

생각할 점:
- 비중이 큰 몇 개에 금액이 몰려 있으면 적게, 고르게 퍼져 있으면 조금 더 많이 본다.
- 월평균 건수가 "최소_월평균건수"보다 적은 칸은 어차피 '기타'로 합쳐지므로 개수를 늘려도 정보가 늘지 않는다.
- 개수 1개마다 변수가 2개씩 늘어난다. 학습 문제가 적어서 너무 많으면 과적합된다.
- 도구로 실제 비중을 확인한 뒤 정한다.

답 형식 (허용 범위 안의 정수):
{"상위지역_수": 3, "상위중분류_수": 2, "이유": "자료·도구 결과의 숫자를 근거로 한두 문장"}
